# FocusFlow — Трекер задач и привычек

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Мобильное веб-приложение для управления задачами, отслеживания привычек и анализа продуктивности. Работает полностью на клиенте — без сервера и регистрации через интернет.

## Возможности

### 🗂 Задачи
- Создание, редактирование, удаление задач
- Фильтрация: все, сегодня, завтра, на неделе, ожидают, выполнены
- Категории (Работа, Личное, Учёба) + свои собственные
- Дедлайны и приоритеты (высокий / средний / низкий)
- Прогресс-бар выполнения за день

### 🗓 Канбан-доска
- Колонки: «К выполнению», «Просрочено», «Готово»
- Перенос задач между колонками перетаскиванием (drag-and-drop)
- Клик по карточке открывает редактирование, чекбокс отмечает выполнение
- Автоматический перенос дедлайна при перемещении просроченной задачи в работу

### 🌱 Привычки
- Отслеживание серий (streak) выполнения
- Календарь отмеченных дней
- Выбор эмодзи-иконки для каждой привычки

### 📊 Статистика
- Графики по неделе / месяцу / году
- Кол-во созданных и выполненных задач
- Прогресс по привычкам
- Достижения: лучшая серия, задач закрыто, отметок привычек

### ⚙️ Настройки
- Светлая / тёмная тема (сохраняется на устройстве)
- Управление категориями
- Экспорт данных в CSV
- Сброс данных

### 🔐 Учётная запись
- Регистрация и вход по имени + телефону + паролю
- Вход по коду (резервный вход без пароля через SMS-код)
- Сброс пароля по коду на телефон
- Хеширование паролей (salt + cyrb53)

> **Демо-режим**: SMS не отправляется — проверочный код показывается прямо на экране.

## Технологии

- **Vanilla HTML / CSS / JavaScript** — без фреймворков, сборщиков и зависимостей
- **localStorage** — все данные хранятся на устройстве пользователя
- Адаптивный мобильный интерфейс, бренд-стиль FocusFlow:
  - Шрифт Inter
  - Градиент `#6366F1 → #818CF8`
  - Один HTML-файл + один CSS + один JS

## Запуск

Откройте `index.html` в браузере или запустите через локальный сервер:

```bash
# Через Python
python -m http.server 8000

# Или через Node.js
npx serve .
```

Затем откройте `http://localhost:8000` в браузере.

Либо через npm:

```bash
npm install
npm start
```

## Деплой на Railway

1. В репозитории должен быть `package.json` (в репозитории есть).
2. На Railway: **New Project → Deploy from GitHub repo** → выберите `focusflow`.
3. Railway сам определит Node.js и запустит `npm start`, который поднимет статический сервер на порту, заданном Railway.
4. На вкладке **Settings → Networking** нажмите **Generate Domain**, чтобы получить публичный URL.

## Тестирование

Автотесты (`lock_test.py`, `kanban_test.py`, `smoke.py`) не входят в репозиторий — это внешние скрипты на Python (py-mini-racer + esprima), которые гоняют `app.js` через эмуляцию DOM. Скопируйте их рядом с `app.js` и запустите:

```bash
python lock_test.py      # регистрация / вход / сброс пароля / вход по коду
python kanban_test.py    # канбан-доска
python smoke.py          # общий смоук
```
